Download the skill bundle and add its folder to your agent's supported skill directory. It includes the references, templates and Python scripts—no private runtime required.

03

Run the offline tests

Requires Python 3.10+. No Python packages or API key are needed for the core starter.

git clone https://github.com/cathy-kim/jev-workflow.git
cd jev-workflow
python3 -B -m unittest discover \
  -s plugins/jev/skills/jev-decisions/scripts \
  -p 'test_decision_kit.py' -v
python3 examples/offline_demo.py

The demo uses synthetic probabilities. A shadow-mode REVIEW recommendation is expected; no downstream action is executed.

02 / Apply

Make the next decision narrow.

Define the evidence, ask one question per dimension, validate the answer, and return a policy recommendation. Test failure paths before introducing live inference.

Support routing“Design typed questions for billing, technical, account and other. Treat missing evidence as review, never as automatic denial.”
RAG evidence gates“Separate passage relevance from answer sufficiency. Preserve citations and access boundaries. Write offline parser tests.”
Agent evaluation“Check tool order and schema in code; reserve semantic judgments for the model. Keep refusal and N/A distinct from a pass.”
Shadow adoption“Produce an evaluation plan with labeled holdout data, uncertainty, cost caps and a rollback path. Do not call a live API.”

04 / Know the limits

Offline first.
Honest about scope.

  • The Python starter validates a limited, normalized text contract. It is not a universal provider adapter or a live TypeSafe client.
  • Synthetic fixtures prove local behavior, not model quality, production compatibility or calibrated thresholds.
  • Live integration needs a separately implemented provider adapter, authorized data, explicit budgets and independent evaluation.
  • The guide is a dated technical reference. Check current official APIs, model versions, pricing and media support before adoption.
  • No internal project data, personal conversation logs, secrets or private Git history are included.
